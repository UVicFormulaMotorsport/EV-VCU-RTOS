\doxysubsection{Detailed Description}
Main driving loop task\+: reads APPS/\+BPS, runs plausibility/safety checks, maps throttle -\/\texorpdfstring{$>$}{>} torque request, applies a torque filter, and sends to motor controller. 

Units convention (used throughout this file)\+:
\begin{DoxyItemize}
\item Raw sensor inputs\+: ADC counts (uint16\+\_\+t)
\item Pedal positions\+: percent \mbox{[}\%\mbox{]} (float, 0.\+0–100.0)
\item Torque values\+: \mbox{[}Nm\mbox{]} (float)
\item Speed feedback\+: \mbox{[}RPM\mbox{]} (int16\+\_\+t)
\item Power limits\+: \mbox{[}W\mbox{]} (float / uint32\+\_\+t)
\item Time\+: \mbox{[}ms\mbox{]} in settings, RTOS ticks internally
\item Omega\+: \mbox{[}rad/s\mbox{]} when converting RPM for power-\/based torque caps 
\end{DoxyItemize}
